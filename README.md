# Hamza Mohamed — Civil Engineer Portfolio

A responsive, interactive, bilingual (English/French) civil engineering portfolio for Hamza Mohamed. Built as a static website using HTML, CSS, and JavaScript: no backend, database, API keys, build step, or paid service required.

## Features
- Responsive desktop and mobile layout
- English/French language toggle
- Interactive project filters and project detail dialogs
- Experience timeline, skills, education, and contact sections
- Scroll reveal animations with reduced-motion support
- Accessible keyboard interactions and mobile navigation
- SEO metadata and favicon
- Clickable email, telephone, and GitHub contact links

## Run locally
Open `index.html` in a browser, or serve the folder with any static file server.

## Deploy to GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Set **Source** to **GitHub Actions**.
3. Pushes to `main` trigger the included deployment workflow.
4. The expected site URL is `https://thegreathamza.github.io/MyCivilPortfolio/`.

## Customize
Edit `index.html`. Search for the portfolio text, experience timeline, project cards, skills, and contact details. The project detail content is stored in the `copy` object in the script near the bottom of the file.

## Notes
- Project descriptions are based on the supplied portfolio content and should be reviewed before public use.
- The current standalone version does not include downloadable CV files. Add the PDF files under a `cv/` directory and link them from the page if you want CV download buttons.
- The contact section uses direct email and telephone links; no contact form backend is used.
